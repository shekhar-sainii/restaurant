# Restaurant Backend API

Advanced Node.js backend for a restaurant management system.

## Stack
- Node.js
- Express
- MongoDB (Mongoose)
- Socket.io
- Razorpay
- Cloudinary

## Setup
1. Clone the repo
2. Install dependencies: `npm install`
3. Copy `.env.example` to `.env` and fill the values
4. Start dev server: `npm run dev`

## Folder Structure
Follows Repository-Service-Controller pattern.
Check `src/modules` for feature-specific logic.
